# 单项3C验收等级与 Godot 同步门

每个单项3C都在 Web 原型中维护一个 `L0–L4` 验收等级。等级属于关卡数据，菜单标题与关卡 HUD 必须同步显示。

| 等级 | 含义 | Godot 同步 |
|---|---|---|
| L0 | 基础玩法仍在调整，关键交互或手感尚未通过 | 不同步 |
| L1 | 基本功能与主要操作通过，可以建立 Godot 对应实现 | 开放 |
| L2 | 单项手感和主要边界情况稳定 | 继续同步 |
| L3 | 已通过综合关卡、资源和其他3C组合验证 | 继续同步 |
| L4 | Web 与 Godot 双边对比通过，可作为正式内容生产基线 | 完成同步 |

等级提升必须由对应单项关卡的真人试玩结论触发。自动测试通过只能作为必要条件，不能自动提升验收等级。
