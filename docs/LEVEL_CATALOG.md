# 3C测试关卡目录

浏览器原型 0.3 包含六个单项关卡和四个综合关卡。单项关卡只授予目标能力及必要的组合测试能力，综合关卡则授予当前全部移动能力。

## 单项3C

| 关卡 | 验收 | 初始能力 | 主要验证内容 |
|---|---|---|---|
| 软绳实验场 | L1 | 软绳、冲刺、墙抓 | 发射回收过程、第一层可见表面、张力绳形、冲刺接绳、物理摆荡与加速收绳 |
| 硬杆实验场 | L0 | 硬杆、冲刺、墙抓 | 墙地斜面及伤害区底部碰撞面支点、冲刺接杆、固定杆长、惯性旋转与主动释放 |
| 猛击实验场 | L1 | 猛击、墙抓 | 近距离六边支点、最长 0.9 秒按住时停选向、松开或超时高速弹射 |
| 二段跳实验场 | L1 | 二段跳、墙抓 | 延迟二跳、补救跳、低顶空间和跨越伤害区 |
| 滑翔实验场 | L0 | 滑翔、墙抓 | 低速长距离下降、增强上升/横向气流、方向与强度反馈 |
| 冲刺实验场 | L0 | 冲刺、软绳、硬杆、墙抓 | 当前朝向、八方向冲刺、落地恢复以及高速接绳接杆 |

## 综合关卡

| 关卡 | 空间结构 | 主要验证内容 |
|---|---|---|
| 综合 · 高速连段 | 短落脚点与连续空中节点 | 动量保持、能力切换、蓝量沿线补给 |
| 综合 · 水平穿越 | 长距离上下双路线 | 安全路线与高速捷径、固定地图学习 |
| 综合 · 垂直升降 | 高塔式上下移动 | 视野方向、向上攀升、滑翔下降和气流 |
| 综合 · 伤害走廊 | 地面、墙面和天花板伤害区 | 受伤上抛、脱离跳、短检查点和连续容错 |

## 当前能力操作

- 软绳：按住左键发射，绳头到达后连接；松开左键解除约束并播放柔软回收过程。绳索只能缩短：连接后按住 `W` 或上方向键快速加速收绳，到达最短长度时获得额外向心速度。墙、平台或斜面会遮挡其后的锚点和表面；高点与松绳时更弯，快速通过低点时更直。
- 硬杆：指向范围内且直线可达的第一层墙壁、地面、斜面或伤害区域底部碰撞面，按 `F` 连接角色与命中点；长度生成后锁定，`A/D` 施加切向力，再按 `F` 释放。
- 冲刺：按 `Ctrl` 朝当前面向冲刺；按住 `W/A/S/D` 或方向键再按 `Ctrl` 可选择八方向。空中一次，落地恢复；冲刺速度可传入随后连接的绳索或硬杆。
- 猛击：进入紫色六边支点范围后按住 `Q` 进入最长 0.9 秒时停，移动鼠标选向；松开 `Q` 立即发射，持续按住则在时停结束时自动按当前方向发射。
- 二段跳：空中再次按 `Space`。
- 滑翔：下落过程中按住 `Space`。
