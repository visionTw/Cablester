# 浏览器原型 0.3 验收记录

## 当前结论

浏览器原型已经通过首轮结构、规则和页面运行检查，可以进入真人手感验收。Godot 迁移尚未开始。

当前单项验收状态：软绳、猛击和二段跳为 `L1`，已开放 Godot 同步开发；硬杆、滑翔和冲刺继续保持 `L0`。

## 已实现

- 固定时间步的跑动、跳跃、土狼时间和跳跃预输入。
- 墙面接触、墙抓、墙跳。
- 方向式目标预览；按住左键后绳头从角色飞向第一层直线可达目标，命中才建立约束；松开立即解除约束并播放柔软回收过程；支持物理摆荡、加速收绳和松绳保留速度。
- 绳索只能缩短：连接后按住 `W` 或上方向键持续收绳；收绳会快速加速，到达最短长度时只触发一次额外向心速度；`Space` 不再承担收绳输入。
- 摆荡输入使用起步脉冲、已有角速度同向泵速和反向比例制动；持续按住方向无法形成抵消重力的固定角度平衡。
- 软绳三次贝塞尔绳形由重力夹角、切向速度和松弛量共同驱动：高点更弯、快速低点更直，并平滑过渡。
- 当前方向及八方向冲刺、空中一次和落地恢复；冲刺途中连接绳索或硬杆会把高速切向惯性传入约束运动。
- 绳索与硬杆的约束运动带独立被动阻尼，连接后从当前惯性开始旋转并逐渐减速，释放后保留当前速度。
- 角色到第一层直线可达墙壁、地面、斜面或伤害区域底部碰撞面的双端硬杆；生成后锁定长度，角色绕固定端旋转，按 `F` 主动释放并保留切向速度。
- 绳索与硬杆共享切向摆荡输入：控制强度平滑插值，同向输入加速，反向输入优先制动。
- 紫色六边猛击支点、近距离目标选择和最长 0.9 秒冻结瞄准；按住 `Q` 选向，松开立即以 960 px/s 弹射，持续按住则超时自动弹射；猛击不识别普通表面。
- 二段跳独立空中次数；滑翔使用更低重力与 190 px/s 下落上限，滑翔期间风力提升到 1.9 倍；进入上升风场时立即获得 300 px/s 向上托举，最高加速到 520 px/s 后匀速，离场后结合滑翔重力与 220 px/s² 额外衰减在约 1 秒内恢复普通滑翔；持续按住时在上升阶段保持展开。
- 五格血量、六格蓝量、能力消耗、能量球、保底回蓝和检查点恢复。
- 伤害、受伤无敌帧、向上击退、短时脱离跳、死亡和手动返回安全点；伤害区具有单向底部碰撞，滞留时每秒扣 1 血；非致命受伤不会主动断绳。
- 数据驱动的能力 ID 和二段跳拾取物。
- 开始界面关卡选择、六个单项3C关卡、四个综合关卡和 `Esc` 返回菜单。
- 固定测试路线、自动旋转房间和随时可用的手动旋转测试。
- 世界旋转时同步改变重力，移动输入保持屏幕左右。
- 目标预览、血蓝 HUD、速度显示、操作提示和调试数据显示。

## 需要真人试玩确认

建议先完成六个单项关卡，再分别尝试综合关卡。重点回答：

1. 朝大致方向发射时，是否能稳定选中想要的锚点或表面？有没有明显锁错目标？
2. 绳长、重力、跑速、`W` / 上方向键快速收绳和松绳速度是否能形成连续节奏？
3. 0.5 蓝一次的软绳消耗是否太强、太弱或基本合适？
4. 绳索和硬杆上的 `A/D` 同向加速、反向制动与插值响应是否符合预期？
5. 第二、第三次通过时，是否能明显比第一次更快、更少停顿？
6. 旋转后是“短暂混乱但能理解”，还是失去了空间判断依据？
7. 掉入伤害坑后，底部碰撞、每秒 1 血和一次脱离跳是否足以形成清楚且可恢复的惩罚？
8. 猛击目标范围、0.9 秒最长时停、按住选向与松开触发、弹射速度和方向控制是否清楚？
9. 滑翔和气流是否具有足够明显的升力差异？
10. 高速、水平、垂直和伤害综合关卡是否各自验证了不同问题？
11. 绳索发射和回收速度是否清楚但不拖慢连续换绳？
12. 八方向冲刺是否容易触发预期方向，空中一次的限制是否清楚？
13. 冲刺接绳、冲刺接杆是否自然继承高速动量，阻尼减速是否过快或过慢？

## 当前有意保留的范围限制

- 美术、动画、声音均为占位表现。
- 敌人、可被猛击的投射物和正式追逐段尚未实现。
- 硬杆目前只验证“固定杆长撑杆跳”，旋转加速度与释放速度仍可根据试玩调整。
- 当前只支持桌面键鼠；手柄与触屏不在 0.3 验收范围。
- `R` 是原型调试入口，正式关卡只会由事件或机关触发旋转。
